## System Requirements & Prerequisites

Before running NeedleThreads for the first time, ensure your development machine has the following tools installed:

- **Node.js**: Version 20.0.0 or higher ([Download Node.js](https://nodejs.org/))
- **npm**: Included automatically with Node.js installation
- **Git**: For cloning the repository

### Quick Start (Linux / macOS)

Simply run:
```bash
git clone https://github.com/LukasLapp/NeedleThreads.git
./start.sh
